# Defence Game

브라우저에서 실행되는 단일 파일(`index.html`) 타워 디펜스 게임입니다.

## 실행 방법
1. 저장소 루트에서 `index.html`을 브라우저로 엽니다.
2. 좌측 상점에서 포탑을 선택한 뒤, 맵을 클릭해 배치합니다.
3. 포탑 선택 후 업그레이드/판매를 사용할 수 있습니다.

## 2026-04 밸런스/콘텐츠 업데이트
- 초반 난이도 완충
  - 웨이브 1~3 적 체력 10% 감소
  - 웨이브 1~3 처치 보상 +3G
  - 대량 웨이브(3의 배수) 시작 시점을 웨이브 6 이후로 조정
  - 웨이브 1~5 한정 첫 판매 보너스(기존 대비 추가 환급)
  - 웨이브 1~5 한정 기본/레이저/머신건 1회 할인
- 신규 포탑 3종 추가
  - 박격포: 공중 공격 가능, 최소 사거리 존재
  - 레일건: 직선 관통 공격
  - 집행자: 체력 낮은 적 우선 처형

## 참고
- 밸런스 파라미터는 모두 `index.html`의 포탑 스탯/웨이브/보상 로직에서 조정할 수 있습니다.
